# Ресёрч: что реально двигает результат в RSNA Knee 2026

Дата: 2026-09-18. Источники: 45 тем форума соревнования (прочитаны через Kaggle API), 14 публичных ноутбуков и датасетов весов, обзор литературы (3 400 слов, в репозиторий не включён), наши собственные OOF-диагностики. Наше положение на момент написания: форк публичного ансамбля 0.939, наша стадия (4 модели r4+r5) с весом 0.15 в бленде дала те же 0.939, наша модель первого раунда 0.750. Верх лидерборда 0.957.

## 1. Главные выводы (в порядке важности)

1. **Сильные результаты дают компактные одиночные модели, а не ансамбли.** Из темы «Best single-model score» (81 комментарий): CoAtNet 224 px, один фолд — 0.950; ResNet небольшой, 224 px, один фолд — 0.949 (это лидер обоих лидербордов, прогон 5 минут); CoAtNet 384 один фолд — 0.937; 5-фолд EffNet/ResNet 224 — 0.943; DINOv2 один фолд — 0.932. Ансамбли из 20+ публичных моделей стоят на 0.939–0.941. Вывод: наша цель не «ещё веса в бленд», а одна своя модель уровня 0.93+.
2. **Разрешение не решает.** Несколько лидеров независимо: 224–288 px — «сладкая точка» для ResNet/EffNet, 384 не даёт прироста. Поле обзора 140–160 мм. Наши 384 px можно снизить до 288 и удвоить число эпох за ту же квоту.
3. **Метки решают, но с потолком.** Мягкие метки лучше жёстких (+0.014 AUC на 3 сидах). Объединение своих меток с публичной таблицей дало +0.015 LB. Согласие таблиц с gold: pilkwang 0.870, stevenleehans v4 0.893, среднее двух таблиц лучше любой одной. Но после уровня ≈0.89 к gold дальнейшая шлифовка меток LB не двигает: «модель-ученик стабильно обходит учителя», в отчётах просто нет части информации. Ключевое — как трактовать «не упомянуто» для каждой находки отдельно (см. §3).
4. **Архитектурные ухищрения на уровне 0.92+ — шум.** Одна команда провела 7 абляций (больший бэкбон, cross-slot attention, top-k pooling, EMA, mixup, длинные расписания, число срезов) — все в пределах 0.008. DINOv2-S → DINOv2-B: +0.0011 при шуме 0.002. Наш пятый раунд с пространственной головой (−0.02…0) укладывается в ту же картину.
5. **Хостинговые LLM API разрешены официально.** Организатор (Po-Hao Chen, 2026-08-09 и 2026-08-27): отправка текста отчётов во внешний API для извлечения меток не считается нарушением, внешние датасеты с некоммерческой лицензией (OAI, MRNet, fastMRI+, SKM-TEA) допустимы, если доступ по клик-соглашению.
6. **Трек эффективности — второй реальный лидерборд.** Считается полное время ноутбука, включая установку и чтение DICOM; GPU разрешён. Лидер основного LB одновременно лидер по эффективности: одиночная модель, 5 минут. 68 % команд из топ-50 основного LB в топ-50 эффективности не входят.

## 2. Рецепт сильнейшей публичной одиночной модели (Raptor, dreaddevelopment, 0.924 → 0.941)

Единственный обучающий ноутбук, который лидеры называют полезным (`dreaddevelopment/knee-mri-training-the-twelve-finding-model`):

| Параметр | Значение |
|---|---|
| Вход | одно исследование = стек 44 × 336 × 336 uint8 из всех серий; окна из 3 соседних срезов как RGB |
| Бэкбон | `coatnet_rmlp_2_rw_384.sw_in12k_ft_in1k`, 384 px, ImageNet-21k; опционально свой SSL-претрен на корпусе |
| Голова | attention-MIL с отдельными весами внимания на каждую из 12 находок (tanh-attention 256), линейный слой на находку |
| Сэмплирование | k=12 случайных окон на обучении, 24 равномерных на валидации |
| Обучение | 16 эпох, batch 8 исследований, AdamW, LR бэкбона 3e-5, головы 1e-3, OneCycle, BCE с pos_weight на мягких целях, gradient checkpointing |
| Регуляризация | никаких аугментаций кроме случайного выбора окон; усреднение весов трёх лучших эпох (бесплатно на инференсе) |
| Валидация | только 58 gold, они не идут в обучение |

Сходства с нашим r4: 2.5D, attention по находкам, мягкие метки. Отличия: 16 эпох против 8, окна из всех серий без плоскостных эмбеддингов, усреднение весов, обучение на всех данных (один фолд).

## 3. Метки: что известно точно

- Только 58 gold. Отчёты молчат о половине экспертно-положительных синовитов; перелом есть в 7 % отчётов и в 31 % экспертных меток («not addressed is a label too»).
- Синовит: 84 % отчётов его не упоминают; поле «выпот» предсказывает gold-синовит лучше, чем поле «синовит» (0.71 против 0.68). Заполнение неопределённых ячеек синовита по выпоту: 0.678 → 0.790 по метке, 0.878 → 0.887 по macro. Обобщение этого приёма на все 12 находок сделало хуже. У нас условный приор 0.45 уже стоит; менять на другие находки не надо.
- Тяжесть находки: эксперты не считают «малый выпот» положительным, но и порог не чистый — в gold есть противоречащие пары одинаковых шаблонных фраз. Наша калибровка по тяжести (порог «умеренная») подтверждена: выпот 0.65 → 0.79 к gold.
- Что не сработало у других: отчёты как вспомогательный лосс (вредит), сложные многопроходные экстракции (переобучение на 58), самообучение по OOF (Tucker: без изменений; Raymond: «главный рычаг» — мнения расходятся).
- Публичные таблицы, которые стоит смешать: `pilkwang/rsna-knee-llm-labels` (0.870), `stevenleehans/rsna-knee-llm-report-labels` (v4 blend 0.893), `barun2104/…llm-soft-labels`, `lixin73/…sol56`. У нас пока только первая плюс свой Qwen (0.826 / 0.850 после калибровки).

## 5. Что даёт литература сверх форума (кратко, подробности в literature.md)

- **DINOv3-ConvNeXt** как бэкбон бьёт ViT-варианты на медицинских задачах; ViT с глубокой разморозкой в публичных репо проигрывает CoAtNet (0.84 против 0.93 на gold). DINOv3-ViT у нескольких участников хуже DINOv2.
- **AUC-margin loss (LibAUC)** после BCE-претрена: +0.003–0.01 на редких метках, устойчив к шуму меток.
- **Confident learning по OOF** (RSNA 2024, 2-е место): снижать вес пар «метка–исследование», где ансамбль уверенно против; не выбрасывать.
- **Domain-randomisation аугментации** (random conv, bias field, histogram matching к другим клиникам): +0.003–0.01 на невиданных сканерах. Наш слабый субсет — турецкая клиника (0.75 против 0.87).
- **TTA без отражений**: сдвиг окна срезов на ±1, джиттер центра кропа ±5 мм, повороты ±5°; геометрическое TTA в медицине часто вредит, проверять на OOF.
- **Дистилляция ансамбля в одну модель** — путь к треку эффективности.
- Не стоит: 3D-сети, DivideMix/co-teaching на 4.4k исследованиях, CutMix между коленями, test-time BN.

## 6. Уроки прошлых RSNA-соревнований (фоновые знания, не свежий поиск)

Lumbar Spine 2024 и Cervical Spine 2022: локализация → кроп → 2.5D CNN → последовательная модель (LSTM/attention) по срезам; крупнейший прирост от кропов и от обучения на всех данных. Abdominal Trauma 2023: 2.5D EffNetV2-S/CoaT + GRU, вспомогательные сегментационные лоссы. ICH 2019 / PE 2020: 2D CNN → последовательная модель по срезам, ансамбли по бэкбонам, rank-averaging. Brain Tumor 2021: метки не обучаемы, никто не превзошёл шум — напоминание, что потолок задаёт разметка. Наш пайплайн уже в этой парадигме.

## 7. Наши диагностики

- r4 OOF к уверенным публичным меткам: macro 0.867 (фолды 1+2). У лидеров такой же CV к отчётным меткам 0.87–0.90 соответствует LB 0.94. **Наш реальный LB одиночной стадии неизвестен** — это самая дешёвая и важная проверка.
- Слабые находки: PF OA 0.80, латеральный мениск 0.81, латеральный OA 0.82, контузия 0.83. У лидеров те же слабые места (PF OA, латеральные, синовит).
- Слабая клиника: турецкие отчёты 0.75.
